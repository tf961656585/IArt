# 组件手册（scripts/pptdeck.py）

> 什么时候读：写 build.py 之前，或遇到某个组件报错时。只读你要用的那一节即可。
> 通用规则：只填内容和枚举选项；坐标、尺寸、字号、颜色、对齐全部由组件库决定，没有参数可以改。
> 字数按"字"计：1 个汉字 = 1，英文/数字约 0.5。超出限制会抛出 `DeckError：第N页 | 组件 | 问题 | 建议修复方式`。
> 所有文字里都不要写 `\n`，换行由组件库计算。

```python
import sys; sys.path.insert(0, "<技能目录>/scripts")
from pptdeck import *
deck = Deck(title="演示文稿所属的项目/文档名", source="每页来源标注的前缀，可留空",
            theme="深蓝")     # theme：深蓝 / 墨绿 / 石墨；可选 image_dir="images"
```

## 页面级方法（直接调用 deck.xxx）

### deck.cover —— 封面
- 用途：第 1 页。
- 参数：`title`（≤20字，必填）、`subtitle`（≤24字）、`author` + `date`（合计 ≤30字）、`notes`、`image`（可选，只能是 `deck.mood(...)`）。
- 示例：`deck.cover(title="设备管理台 v2 改版说明", subtitle="给一线运维的使用变更", author="张三", date="2026年10月", image=deck.mood("现代化的运维值班室"))`

### deck.points —— 要点页（整页编号条目）
- 用途：目标、议程、要点清单、结论清单。通常放在封面之后。
- 参数：`items`（1–6 条，每条 ≤30字）、`source`（可选）、`title`（默认"要点"）、`notes`。
- 示例：`deck.points(["看懂三个主要变化", "知道迁移要注意什么"], title="今天讲三件事", source="§1")`

### deck.section —— 章节过渡
- 用途：每一节开头一页，显示全部节名并高亮当前节。节数少于 2 时不要用本组件。
- 参数：`sections`（2–8 个节名，每个 ≤12字，每次调用都传同一份列表）、`current`（从 1 开始）、`notes`、`image`（可选氛围图，几节可以共用一张）。
- 约束：同一节只能有一页过渡页。
- 示例：`deck.section(["为什么改", "三个主要变化", "迁移与风险"], current=1)`

### deck.slide —— 内容页（容器）
- 用途：除封面/要点页/章节/小结外的所有页面。一页 = 一句结论标题 + 1–2 个内容组件。
- 参数：
  - `title`：一句完整的结论（≤32字、≤2行，全套唯一）。写"接地线接错会让外壳带电"，不写"接地线"。
  - `blocks`：1–2 个组件（下文的 Evidence / Definition / Bullets / Steps / Compare / Example / Question / Alert / Table）。
  - `source`：本页内容的来源，可选，如 `"§2.1"`、`"P45 图3-2"`、`"设计稿 v2"`。
  - `source_note`：来源标注的补充说明（≤20字），页脚显示为【…】并计入质检报告，如 `"含补充资料"`。
  - `notes`：讲者备注，写完整讲解（缺了会被警告）。
  - `layout`：两个组件时 `"自动"`（默认）/`"左右"`/`"上下"`。自动规则：Steps、Compare、Example、Table、Alert 会上下排，其余左右各半。
  - `decor`：可选氛围图，只允许用于"只有 1 个 Question"的页面，全套最多 3 页。
- 约束：同一页 Definition、Alert、Question 各最多 1 个；两个组件放不下会报错，按提示拆页。

### deck.image_page —— 整页图片页（还原设计稿）

- 用途：一张整页画面 1:1 铺满画布，**不画标题、不画顶部色条与页脚线**。设计已定（有设计稿/参考图、
  或上一版是图片课件）时用它，不要拿内容组件去"重排"设计。
- 参数：`image`（`deck.image(...)` 或本地图片路径字符串）、`caption`（≤40字，压在底部）、
  `page_no`（默认 True）、`fit`（`"contain"` 等比铺满留白 / `"cover"` 裁边铺满）、`notes`。
- 约束：没有标题，因此不参与"标题唯一"判定；仍要求写 notes，否则质检会警告备注缺失。
- 示例：`deck.image_page("assets/slide-01.png", notes="第 1 页讲稿")`

### deck.hero —— 主视觉页（图打底 + 标题压图）

- 用途：整页图铺满（裁边），再用一块主色面板压住标题；适合封面/章节/金句页。
- 参数：`image`、`title`（≤32字，仍受全篇唯一约束）、`subtitle`（≤30字）、
  `position`（`"left"` 左侧竖条 / `"bottom"` 底部横条）、`page_no`、`notes`。
- 示例：`deck.hero("assets/cover.png", "从卖产品到占心智", subtitle="一节课看懂五步法", position="bottom")`

### 设计令牌（Deck 的 theme 参数）

`Deck(theme=...)` 可以传内置主题名（深蓝/墨绿/石墨），也可以传一份 dict 只写要改的键：

| 键 | 默认 | 说明 |
|---|---|---|
| `primary` / `accent` | 随主题 | 主色 / 强调色（6 位十六进制，会校验与白色的对比度 ≥4.5） |
| `bg` | `FFFFFF` | 页面底色，深色课件改这里；整页图留白也用它 |
| `text` / `gray` / `line` | 深灰 / 中灰 / 浅灰 | 正文、辅助文字、分隔线 |
| `font` | `Microsoft YaHei` | 字体名；**必须在演示机器上存在**，否则会掉字 |
| `chrome` | `True` | 是否画顶部色条 + 页脚线 + 页码 |
| `scale` | `1.0` | 全局字号倍率，0.7–1.3；放大后会有更多页放不下 |
| `title_size` / `body_size` / `small_size` / `foot_size` | 32/24/18/14 | 四档字号基数 |

### deck.summary —— 小结
- 用途：最后一页。
- 参数：`points`（1–6 条，每条 ≤25字）、`source`（可选）、`prompt`（可选的提问，≤30字）、`title`（默认"小结"）、`notes`。
- 示例：`deck.summary(["查找与批量操作收进同一页", "权限不足时按钮禁用"], source="§1–§4", prompt="如果当天出问题，第一步做什么？")`

### deck.save —— 保存与质检
- `deck.save("演示.pptx")`：写出 pptx、`演示_QA.txt`（质检报告）和同目录的 `image_requests.json`，并打印报告。

## 内容组件（放进 deck.slide 的 blocks）

### Evidence + Callout —— 图片证据（断言 + 证据）
- 用途：用一张图支撑标题里的结论。**标题是断言，图是证据**。
- 参数：
  - `image`：`deck.image(...)`（本地图片）或 `deck.illustration(...)`（插图）的返回值。**不能传路径字符串，不能传氛围图。**
  - `placeholder`：还没有图时写明应放哪张图，如 `"新旧流程对比图"`。
  - `callouts`：标注列表 `Callout(文字, x, y)`，≤4 个，每个 ≤16字；x、y 是被标注部位在**图片**中的相对位置（0~1，左上角为 0,0）。部位必须可信时再标：本地图片可以标，AI 插图的部位不保证准确。
  - `caption`：图注，可选。标注 + 图注总字数 ≤40。
- 系统自动：图下来源标签（本地图片 → "本地图片 <source>"；插图 → "插图（AI生成，仅辅助理解）"）；两个 Evidence 同页时左右对比排列。
- 示例：
```python
deck.slide("新版把查找和批量操作收进同一个页面", [
    Evidence(image=deck.image("assets/console.png", source="设计稿 v2 · 主界面"),
             callouts=[Callout("顶部搜索与筛选", 0.50, 0.07), Callout("批量操作", 0.86, 0.93)])],
    source="§2.1 主界面", notes="……")
```

### Definition —— 概念卡片
- 用途：术语、概念、定义。
- 参数：`term`（≤12字）、`definition`（≤60字，写完整短语）、`note`（补充说明，≤40字，可选）。
- 约束：每页最多 1 个。定义超过 60 字：只保留核心句，其余放 note 或 notes。
- 示例：`Definition(term="停机窗口", definition="系统不可用、但允许停机的连续时间长度。", note="本次窗口为 6 小时。")`

### Bullets —— 要点列表
- 用途：真的只是几条并列/顺序/递进/因果的短句时才用；**不是默认选项**（全套超过 30% 的页用列表会被警告）。
- 参数：`items`（2–5 条，每条 ≤20字，必须一行放得下）、`relation`（`"并列"`/`"顺序"`/`"递进"`/`"因果"`，决定编号和箭头样式）。
- 示例：`Bullets(["按台账逐级查找", "筛选条件只能单选", "找不到就导出表格"], relation="因果")`

### Steps + Step —— 步骤流程
- 用途：操作步骤、工序、流程（"做什么 + 要点 + 为什么"）。
- 参数：`Steps([Step(action, key_points, reason), ...])`
  - 每页 3–6 步；整项流程超过 9 步请拆成两个、两页（第二页标题加"（续）"）。
  - `action`：动词开头，≤12字；`key_points`：0–2 条，每条 ≤20字；`reason`：≤30字，写**具体后果**，禁止"为了安全""保证质量"之类空话。
- 示例：`Steps([Step("勾选设备", ["一次最多 200 台"], "超过上限提交会超时"), Step("确认影响范围", ["显示命中台数"], "避免误操作整批设备"), Step("提交并等待结果", ["结果异步返回"], "提交后可以先离开页面")])`

### Compare —— 对比
- 用途：2–3 个对象在 2–5 个维度上的对比，包括正误对比。
- 参数：`headers`（2–3 个对象，每个 ≤10字）、`rows`（`[(维度名≤6字, [各对象内容…]), …]`，每格 ≤15字）、`marks`（正误对比时**必须**给，如 `["✓", "✗"]`；数量与 headers 一致）。
- 示例：`Compare(headers=["旧版", "新版"], rows=[("入口", ["台账 > 设备 > 查找", "首页搜索框"]), ("筛选", ["一次只能选一个条件", "多条件叠加"])])`

### Example —— 示例讲解
- 用途：把一道题、一个估算或一个任务的分步做法讲清楚。
- 参数：`problem`（≤80字）、`steps`（每页 ≤5 步，每步 ≤30字，不能跳步）、`answer`（≤30字）、`blank_from`（可选：从第几步起留空，请听众现场补全；完整步骤自动写入备注）。
- 示例：`Example(problem="1 万条记录迁移约 4 小时，停机窗口 6 小时，够不够？", steps=["导出旧数据：约 2 小时", "转换与校验：约 1 小时", "导入并回滚预留：约 3 小时"], answer="4 小时刚好够，但没有余量")`

### Question —— 现场提问
- 用途：投票、思考题、互动问答；**参考答案与解析页自动生成在下一页**（也计入页数）。
- 参数：`question`（≤60字）、`kind`（`"选择"`/`"判断"`/`"简答"`）、`options`（选择题 2–4 个，每个 ≤20字；判断题自动为 正确/错误）、`answer`（≤30字）、`explanation`（≤60字）。
- 约束：每页最多 1 个。答案与解析会自动写进讲者备注，页面上也生成答案页。
- 示例：`Question(question="迁移约 4 小时，窗口 6 小时，最稳妥的做法是？", kind="选择", options=["一次性迁移", "分两批迁移", "跳过校验"], answer="B. 分两批迁移", explanation="分批把每次的风险和回滚窗口控制在一半以内。")`

### Alert —— 警示框
- 用途：风险提示、注意事项、易错点。
- 参数：`level`（`"提示"` / `"注意"` / `"警告"` / `"危险"`，严重程度递增）、`subject`（提示什么）、`impact`（会造成什么后果）、`action`（怎么避免）——三段必填，各 ≤25字。
- 约束：每页最多 1 个；可以和另一个组件同页（自动放在下方）。警示色只在本组件出现，不要用它来表达"重要"或"强调"。
- 示例：`Alert(level="注意", subject="客服账号默认没有批量操作权限", impact="提交会收到 403，操作记录会留痕", action="走权限申请流程，或用管理员账号")`

### Table —— 表格
- 用途：参数表、规格表、对照表。
- 参数：`headers`（2–5 列，每格 ≤12字）、`rows`（1–6 行，每格 ≤12字）；不支持合并单元格（空格填 `"—"`）。
- 超限时：拆成两页，或只保留本页要用的行，其余写"见完整清单"。
- 示例：`Table(headers=["时间", "动作", "谁负责"], rows=[["20:00", "停止旧系统写入", "值班运维"], ["20:30", "导出并校验数据", "值班 DBA"]])`

### 来源标注条
- 不用单独调用：每页底部自动显示 `来源：{deck.source}　{本页 source}`（两者留空则不显示），设了 `source_note` 时追加【…】；页码始终显示在右下角。

## 图片引用（详见 images.md）
- `deck.image(path, source="", ratio=None)` → 本地图片（等比放入不裁切；ratio 不填按图片实际比例取最接近的一档）
- `deck.illustration(subject, ratio="4:3")` → 插图（AI 生成）
- `deck.mood(subject, ratio="3:4")` → 氛围图（AI 生成）
- ratio 只能是 `"16:9"` / `"4:3"` / `"1:1"` / `"3:4"`

## 选哪个组件（快速判断）
| 内容形态 | 首选组件 |
|---|---|
| 有实拍图、截图、现成图表 | Evidence（本地图片，可加标注） |
| 术语、概念 | Definition |
| 操作步骤、工序、流程 | Steps |
| 正确 vs 错误、两种做法 | Compare |
| 参数、规格、时间表 | Table |
| 一道题 / 一次估算 / 分步做法 | Example，后面常跟一个 Question |
| 想让大家现场想一想、投票 | Question（自动生成答案页） |
| 风险、注意事项、易错点 | Alert |
| 几条短句的因果/顺序 | Bullets（最后才考虑） |
