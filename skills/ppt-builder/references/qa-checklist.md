# 质检清单与修复循环

> 什么时候读：build.py 第一次跑通之后、交付之前。
> 三层质检：组件层、布局层由组件库自动完成；内容层和视觉层需要你自己核对。

## 1. 组件层（自动，生成时逐页）
字数、条数、枚举值、必填项、空话、标题重复等。超限立即抛出：
`DeckError：第N页 | 组件 | 问题 | 建议修复方式`
脚本会在第一个错误处停止——修好一个再跑，直到跑通。

## 2. 布局层（自动，生成时逐页）
文字测量后放不下、两个组件上下排超高、标注区太窄、图片规则（数量、类型、位置）等，同样以 DeckError 报出。

## 3. 整体质检报告（自动，`deck.save()` 时打印并写入 `*_QA.txt`）
- 【必须修复】：标题重复、只有封面没有内容页、图片未生成或缺失……
- 【建议修复】：缺讲者备注、列表页过多、图片分辨率不足、裁切过多、图片未使用……
- 【来源标注清单】：填了 `source_note` 的页面，交付时原样附上请用户确认。
- 【图片】：待生成的 AI 图清单。

## 4. 内容层（你逐项核对，写进交付报告）
- [ ] 每页文字与它的 `source` 对得上（回到原始材料逐条核对）。
- [ ] 数字、单位、时间、步骤顺序与材料一致；没有凭常识补充的内容（补充的已在页面或 notes 里标明来源）。
- [ ] 只读全部标题，能串成这条主线的逻辑；没有"话题式"标题。
- [ ] 提问（Question）的答案正确，解析与材料一致；答案页文字通顺。
- [ ] Alert 的等级与实际风险相符，没有夸大也没有弱化。
- [ ] 讲者备注完整，讲者照着能讲。
- [ ] 没有把不确定的内容写成确定结论；地方性的、可能过期的信息已提示用户复核。

## 5. 视觉层（需要渲染）
渲染：`bash <技能目录>/scripts/render.sh 演示.pptx render` → `render/page-*.png` 和总览 `render/contact.png`。
先看总览，再**逐页**打开 page-*.png 检查：
- [ ] 文字没有溢出、截断、重叠；没有异常大的空白。
- [ ] 标注引线指向正确部位，标签不压住图片关键部分。
- [ ] 占位框只出现在你预期的地方（未生成的 AI 图 / 用户还没给的本地图片）。
- [ ] AI 图按 images.md 第 5 节的视觉清单检查（乱码文字、准确内容、清晰度、风格一致）。
- [ ] 封面、章节页的文字清晰可读；页脚来源与页码没有越界。
没有 LibreOffice 无法渲染时：在交付报告写"未做渲染检查"，并提醒用户打开 pptx 逐页查看。

## 6. 修复循环
1. 按报错/报告的"建议修复方式"**修改 build.py 的内容**，然后重跑。允许的修法只有：删减文字、拆页（标题加"（续）"）、换组件、重新生成图片。
2. **禁止**：缩小字号、修改 pptdeck.py、用 try/except 吞掉错误、直接用 python-pptx 改页面、自己裁图或在图上写字。
3. 同一页（或同一张图）最多修 3 轮。3 轮后仍不行：把该页改成最简单的形式（一个 `Evidence(placeholder=...)` 或一个 `Bullets`），在 notes 写"【需人工检查】原因：……"，继续往下做。
4. 【必须修复】全部清零后才能交付（未生成的图除外——环境没有生图能力时，保留占位并在报告说明）。

## 7. 交付报告模板
```
演示文稿：XXX.pptx（共 N 页，其中参考答案页 M 页）  构建脚本：build.py
1. 运行中的报错与修复：第N页 | 问题 | 怎么改的
2. 质检报告原文：（粘贴 save() 输出）
3. 来源标注清单：……
4. 【需人工检查】页面：……
5. 图片清单：id | 类型 | 页码 | 视觉检查结果；未生成的图 / 需用户提供的本地图片
6. 渲染检查：已做（逐页查看）/ 未做（原因）
7. 内容层自查：第 4 节逐项结果
8. 需要用户确认或补充的内容：……
```

## 几何核对：`scripts/qa.py`（不用自己写探针）

`deck.save()` 会自动调用它，并把结果附在质检报告末尾（`【几何核对】` 段）。也可以单独跑：

```bash
python <SKILL_DIR>/scripts/qa.py 演示.pptx            # 人读
python <SKILL_DIR>/scripts/qa.py 演示.pptx --json     # 机读（--json-out 落文件）
```

它只做几何/存在性判断（不做审美）：形状越界、文字疑似丢失、占位残留（TODO/待补）、讲者备注覆盖率、
标题重复/高度相似、图片有效 DPI、文字重叠疑似、字体清单。退出码：0 无 fail、1 有 fail、2 打不开。

**校验错误一次性给全**：内容/排版问题不再"抛一个停一次"。一次运行会把所有页的所有组件问题列全，
并且**不写出 pptx**；按清单一次改完再跑。报告里的"校验未通过、已跳过渲染的页"就是本轮没排上的页。

**中文渲染成豆腐块**时先跑 `check_env.py` 的渲染探针：macOS 的 PingFang/Heiti 是 `.ttc` 集合，
headless 导出常常认不到（fc-list 有、渲染没有）。修法是把任一中文 TTF 复制进
`/Applications/LibreOffice.app/Contents/Resources/fonts/truetype/`。
