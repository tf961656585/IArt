# 全局版式与内容规则

> 什么时候读：规划大纲时（页数、结构）、或想知道"组件库为什么这样排"时。
> 版式部分全部由 `scripts/pptdeck.py` 自动执行，你**不需要也不能**手动设置；这里列出来是为了让你理解报错、规划内容。

## 1. 整份结构（推荐，不是硬性要求）
1. 推荐顺序：封面 → 要点页（1–6 条）→ 各节（节多时用章节过渡页；只有 1 节就直接进内容页）→ 小结。
2. 页数经验值：按讲解节奏估，一页通常讲 1–2 分钟；用户给了页数上限就按上限，参考答案页也计入。
3. 一页只讲一个结论；标题是一句完整的结论，≤32 字、≤2 行，全套不重复。
4. 要点列表（Bullets）页不超过内容页的 30%；能画图/流程/对比的改用 Evidence / Steps / Compare / Table。

## 2. 每页规则
1. 每个内容页 1–2 个组件；Definition / Alert / Question 每页最多 1 个。
2. 每页最多 1 张图；只有两张图左右对比时可放 2 张。氛围图（装饰）不进讲内容的页面。
3. `source` 可选：填了就在页脚显示"来源：…"。有材料出处时填上——观众会问"这个数字哪来的"。
4. `notes` 写完整的讲解词（讲者照着能讲），屏幕上只放关键词和结论。
5. 放不下时只有三种修法：删减文字 / 拆页（第二页标题加"（续）"）/ 换组件。**不要缩小字号，不要绕过报错。**
6. 内容是真的：材料里没有的数字、人名、时间不要编；确实需要时向用户要，或在 notes 里写明"此处待补"。

## 3. 组件库自动执行的版式（供理解）
| 项目 | 规则 |
|---|---|
| 画布 | 16:9（960×540pt），左右边距 48pt，12 栏网格，栏间距 16pt |
| 区域 | 标题区 24–108pt；正文区 140–476pt；页脚 492pt 起 |
| 字号 | 标题 32 / 正文 24 / 次要 18 / 页脚 14（pt），不缩放；行距 1.3 倍 |
| 字体 | 微软雅黑（缺失时由系统替换为其他中文字体） |
| 颜色 | 主题色 + 强调色；正文与背景对比度 ≥4.5:1；警示色只在 Alert 组件出现 |
| 间距 | 组件间 24pt，卡片内边距 16pt，统一 8pt 网格 |
| 两组件排列 | 默认左右各半（每侧 432pt）；Steps/Compare/Example/Table/Alert 自动上下（Alert 放下方） |
| 图片 | 本地图片等比放入不裁切（四周留白）；AI 图居中裁切；固定比例 16:9 / 4:3 / 1:1 / 3:4；统一圆角 8pt + 1pt 灰边 |
| 文字测量 | 中文按 1 字宽、英文约 0.55 字宽估算，偏保守；放不下即报错，绝不偷偷缩字 |

## 4. 措辞规则
1. 标题写结论，不写话题："查找从五步缩短到两步"✓，"查找流程"✗。
2. 术语、编号（章节号、图号、表号）沿用材料原文；引用的定义、规定、数值不要改写。
3. 步骤理由写具体后果（"超过上限提交会超时"），不写"为了安全""保证质量"。
4. 不要在文字里写 `\n`，不要用表情符号做装饰（警示框的 ⚠ 由系统加）。
5. Alert 只在真有风险或真有易错点时用；把它当成"强调色块"会让人对真正的警告麻木。
