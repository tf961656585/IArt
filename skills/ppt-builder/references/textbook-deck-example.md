# 示例：用本技能做可溯源的教材课件

> 什么时候读：用户给的是教材/课本/讲义，要求做**可溯源**的课件或培训材料时。
> 这份文档只是**做法示例**：组件库不校验页码、不校验"目标—练习"对应，全靠你自己守。要做普通汇报，不需要读这份文件。

## 1. 与通用流程的差异

| 环节 | 通用做法 | 教材课件这样做 |
|---|---|---|
| 输入 | 用户给大纲/要点 | 先整理一份**带页码锚点的材料草稿**，再出大纲 |
| 每页来源 | 可选 | 必填：每个内容页都写页码，`source="P45 图3-2"`、`deck.source="《电工技术基础》"` |
| 非教材内容 | 直接写 | 用 `source_note="补充"` 标在页脚，并在交付时单列清单 |
| 定义 | 写清楚即可 | **逐字引用教材原文**，不改写 |
| 结构 | 推荐结构 | 学习目标 → 各节 → 小结：目标用可观察动词、每条目标至少一道提问、小结条数与目标条数对应 |
| 图 | 有图就用 | 涉及接线、符号、读数、数据的内容**只能用教材原图或组件**，绝不用插图 |
| 警示 | 风险提示 | Alert 等级与教材表述一致，不夸大不弱化 |
| 交付 | 演示文稿 + 报告 | 另附材料草稿、【补充】与【待确认】清单，请讲师确认 |

## 2. 材料草稿（带页码锚点）

先把材料整理成 `textbook_draft.md`，后面的大纲、每页内容、来源页码、内容层核对都以它为准。它是你和讲师共享的"事实底稿"，不是课件。规则：

1. **只摘录，不发挥**：每一条都来自教材，并带页码锚点 `[P45]`、`[P45 图3-2]`、`[P42 表3-1]`、`[P43 例3-1]`。
2. 定义、规定、数值、步骤用**原文**（可以删减，不能改写意思）；自己的归纳写在"教学提示"里，与原文分开。
3. 看不清、缺页、有歧义：照原样记录并标【待确认】，写明原因，例如 `【待确认】P46 第3行模糊，疑为"36V"`。**不要猜测补全。**
4. 教材之外的内容（讲师口述要求、你认为必要的补充）只能放在"补充"区，逐条标【补充】并写来源（如"讲师要求""行业常识"）。
5. 教材里的图：记录图号、页码、图里有什么、是否已有扫描件（文件名），以及适合做哪页的 Evidence。

模板：

```markdown
# 教材草稿：《教材名》 第3章 安全用电（P40–P49）
课时：90 分钟   材料来源：讲师拍照 P40–P49（P47 缺页）

## 知识点
- [P41] 电流通过人体的伤害程度与电流大小、通电时间、电流路径有关。
- [P42] 安全电压：（原文）……。【待确认】P42 第5行反光看不清

## 定义（原文）
- 安全电压 [P42]：“……（逐字）……”

## 数据 / 表格
- [P42 表3-1] 安全电压等级：42V 手持电动工具；36V 一般场所照明；……（列出本课要用的行）

## 操作步骤
- [P48] 停电验电：① 断开电源 ② 挂警示牌 ③ 检查验电笔 ④ 逐相验电 ⑤ 确认无电后作业

## 图
| 图号 | 页码 | 内容 | 扫描件 | 用途建议 |
|---|---|---|---|---|
| 图3-2 | P45 | 三孔插座面板，标 E/N/L | assets/P45_fig3-2.png | Evidence + 3 个标注 |

## 补充（非教材）
- 【补充】讲师要求：加入宿舍违规电器案例（来源：讲师口述）

## 教学提示（我的归纳，不是教材原文）
- 学生易混：左零右火的"左右"以面对插座为准。
```

## 3. 教学结构（做法，不是校验规则）

- **学习目标**用 `deck.points(...)`，2–4 条，每条以可观察动词开头（说出、列举、解释、计算、操作、判断、比较、选用、绘制）；避免"了解、掌握、熟悉、知道"这类说不清怎么检验的词。
- **每条目标至少一道 Question**，题干里体现要检验的能力；Question 的答案页会自动生成。
- **每道 Example 之后紧跟一道同类 Question**（同页或下一页）。
- **小结**（`deck.summary`）条数与学习目标条数一致，逐条对应。
- 章节数 2–8，每节开头可以用一页章节过渡。

## 4. 准确内容优先用教材原图

- 接线、电路/电气符号、仪表读数、数据、公式、图表、刻度、尺寸、操作手势——**只能用本地图片（教材原图扫描/截图）或组件**（Steps / Table / Compare / Example），**绝不能用插图**：AI 图不保证准确，画错了还很难被发现。
- 讲师还没给扫描件：先问他要；暂时没有就用 `Evidence(placeholder="教材图3-2 三孔插座")`，并在交付报告里列出。讲师的扫描件放到工作目录 `assets/`，用 `deck.image("assets/P45_fig3-2.png", source="P45 图3-2")` 引用。
- 教材原图可以加注释（`Callout`），位置填被标注部位在图片里的相对坐标。

## 5. 最小示例

```python
deck = Deck(title="第3章　安全用电基础", source="《电工技术基础》", theme="深蓝")

deck.cover(title="第3章　安全用电基础", subtitle="触电防护与插座接线", author="张老师", date="2026年10月",
           image=deck.mood("整洁明亮的配电房，一排配电柜"))
deck.points(["说出安全电压的五个等级", "判断三孔插座接线是否正确"], source="P40",
            title="学完本节课，你能够：")

deck.slide("安全电压按环境分为五个等级", [
    Definition(term="安全电压", definition="（逐字引用教材原文，≤60字）"),
    Table(headers=["额定值", "场所"], rows=[["36V", "一般照明"], ["12V", "潮湿场所"]])],
    source="P42 表3-1", layout="左右", notes="……")

deck.slide("三孔插座接线：左零右火上接地", [
    Evidence(image=deck.image("assets/P45_fig3-2.png", source="P45 图3-2"),
             callouts=[Callout("上孔：接地线 E", 0.50, 0.31), Callout("左孔：零线 N", 0.40, 0.66),
                       Callout("右孔：火线 L", 0.60, 0.66)])],
    source="P45 图3-2", notes="面对插座面板讲左右，避免学生弄反方向。")

deck.slide("判一判：插座零火线能否互换", [
    Question(question="左孔接火线、右孔接零线，用电器照样能工作，所以可以这样接。", kind="判断",
             answer="错误", explanation="开关断开后用电器仍可能带电，维修时易触电。")],
    source="P46", notes="请两位同学说理由。")

deck.slide("潮湿环境会让触电风险成倍增加", [
    Evidence(image=deck.image("assets/P41_fig3-1.png", source="P41 图3-1"), caption="教材原图")],
    source="P41 图3-1", notes="潮湿使人体电阻下降，同样电压下电流更大。",
    source_note="含讲师补充的宿舍案例")

deck.summary(["安全电压五级：42、36、24、12、6V", "插座接线：左零右火上接地"],
             source="P40-46", prompt="用一句话说出今天最重要的规则")
```

## 6. 交付时额外附上

- `textbook_draft.md`（材料草稿）；
- 【补充】内容清单与【待确认】内容清单（页面里标了 `source_note="补充"` 的也会出现在质检报告的来源标注清单里）；
- 【需人工检查】页面清单；
- 请讲师确认：页码与内容是否对得上、定义是否逐字、Alert 等级是否与教材一致。
